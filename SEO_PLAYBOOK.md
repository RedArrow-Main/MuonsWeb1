# Muons Technology SEO Playbook

## Positioning and search themes

The site should consistently own a focused topic cluster around American patent-pending edge hardware infrastructure, global food security, offline-first AI for agriculture, farmer-first physical infrastructure, ground agriculture data, and blockchain-backed agricultural records. These themes are used in the homepage, the curated solution pages, the field note, metadata, internal links, and structured data.

## Implemented in code

The site now has a descriptive title and meta description, canonical URL handling, Open Graph and Twitter cards, a fixed public favicon and social image, Organization JSON-LD, crawl directives, a sitemap, image alt text improvements, prioritized hero loading, lazy loading for below-fold media, security and cache headers, and internal links to four curated SEO pages.

The programmatic layer is intentionally curated rather than mass-produced. It includes three solution pages and one insight page with unique titles, descriptions, introductions, section bodies, related links, route-aware metadata, and route-aware JSON-LD. New pages should be added only when Muons has distinct evidence, expertise, or first-hand value to contribute.

## Technical SEO operations after deployment

Verify the production URLs in Google Search Console, submit `/sitemap.xml`, inspect the homepage and each curated route, and monitor indexing, Core Web Vitals, query impressions, click-through rate, and crawl errors. Validate the Organization and Service/Article JSON-LD using Google’s Rich Results Test after deployment.

## On-page editorial rules

Maintain one descriptive H1 per page, use section headings that explain the subject rather than repeat keywords, write image alt text for meaningful images, keep patent language explicitly pending, and avoid claims of guaranteed prediction, certification, or invulnerability. Every solution page should answer a real audience question and link to a relevant next page.

## Programmatic SEO guardrails

Use the shared `seoPages` data model and `SeoTopic` template for a limited, evidence-led content cluster. Do not create location pages, industry pages, or keyword variants with the same text. Each future page should have a distinct search intent, original Muons information, a human reviewer, a canonical URL, and a meaningful internal-link relationship.

## Off-page authority plan

Muons should establish consistent public company facts across its official website, LinkedIn company profile, leadership profiles, relevant patent references, and reputable agricultural or infrastructure directories. Pursue editorial links through original field infrastructure explainers, founder interviews, university or research collaborations, agricultural associations, conference speaking, and citations from organizations that independently reference Muons work. Do not buy links, publish private-network pages, exchange artificial links, or submit the company to irrelevant directories. All external profiles and claims require owner approval and account access.
