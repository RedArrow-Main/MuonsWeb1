# Updated Reference — Adaptable Ideas

The updated reference expands the original landing-page approach into a more information-rich agricultural infrastructure narrative. Its strongest transferable qualities are the **evidence-led hero**, concise **status chips**, an explicit **four-step value chain**, a persistent **signal ticker**, and focused product categories. These should inform Fieldwise’s existing Field Ledger design without copying Muons’ wording, claims, metrics, investor content, or specific product positioning.

| Reference pattern | Fieldwise adaptation |
| --- | --- |
| Hero evidence chips beneath the core message | Add Fieldwise “field record” chips that frame its role in crop, climate, and operations intelligence without numerical or product claims. |
| From-ground-truth-to-value process | Add a four-part Fieldwise “season cycle” that explains Observe, Interpret, Coordinate, and Carry Forward. |
| Persistent scrolling proof / status strip | Add a refined dark signal ribbon that repeats Fieldwise’s operating principles: Local context, Shared view, Timely action, Season memory. |
| Product categories and tabbed sensor intelligence | Build a concise “signals we connect” section with static category chips and an active editorial explanation rather than inventing a technical dashboard or simulated data. |
| Layered platform architecture | Use a lightweight “field record” stack to demonstrate how Fieldwise connects observation, context, coordination, and action. |

The reference’s dense dark-grid pattern, badge-rich detail, and clear step-based storytelling can sharpen Fieldwise’s dossier character. The adopted design must retain Fieldwise’s warm linen sections, DM Serif editorial hierarchy, asymmetrical layouts, and restrained use of Signal Sprout for active meaning.
